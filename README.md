# luolirui.github.io

个人学术主页（Jekyll 静态站点，基于 al-folio 主题）。

## 本地预览

```bash
./bin/dev
```

浏览器打开 `http://localhost:8080`。

## 我一般改哪里

- 首页/自我介绍：`_pages/about.md`
- 论文列表：`_bibliography/papers.bib`（缩略图在 `assets/img/publication_preview/`）
- News：`_news/`
- Experiences（首页展示的 posts）：`_posts/`
- 全局配置：`_config.yml`

更详细的维护指南见：`docs/EDITING_GUIDE.md`。
